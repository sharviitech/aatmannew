# Aatman — static website

Plain HTML/CSS export. Nothing to build or install.

Pages: index.html (home), about.html, services.html, contact.html
Assets: assets/styles.css and images.

## Publish on GitHub Pages
1. Create a new repo on GitHub and upload all of these files (keep the folder structure and the `.nojekyll` file).
2. Repo Settings → Pages → Source: "Deploy from a branch" → branch `main`, folder `/ (root)`.
3. Your site goes live at https://<username>.github.io/<repo>/

Notes: the enquiry forms are static (no backend) — replace them with Formspree/Google Forms or an email link. The video, WhatsApp link and prices are still placeholders.
